4AI 短评引擎（核心）

把四维度数据按统一模板组装成提示词，交由模型推理，强制输出以下结构（便于前端卡片化呈现）：

系统：你是资深短线交易分析师。基于下列【筹码峰】【资金面】【K线】【重大消息】四维度数据，
对用户指定的股票做客观短评。风格：简洁、有依据、不喊单、提示风险。
输出严格 JSON：
{
  "chip":"筹码峰解读（集中度/获利盘/压力支撑）",
  "fund":"资金面解读（主力/北向/融资动向）",
  "tech":"K线技术解读（形态/MACD/量能）",
  "news":"重大消息面解读（利好利空，标注时效）",
  "summary":"一句话综合短评",
  "strategy":"短期应对策略（持仓/观望/风控分点）",
  "forecast":{
     "base":"基准情景(概率)",
     "bull":"乐观情景(概率)",
     "bear":"悲观情景(概率)"
  }
}

前端据此渲染四张维度卡 + 综合短评 + 策略 + 三情景预测。该 schema 与模型无关，hy3/step5 共用。

5hy3 / step5 模型切换设计

分析编排层内置「模型路由」，同一套提示词与输出 schema，仅切换底层推理模型。前端放一个开关即可热切换。

# config（环境变量 / 前端开关写入）
MODELS = {
  "hy3":   {"base_url":"<hy3端点>", "api_key":"<KEY>", "model":"hy3",   "default":true},
  "step5": {"base_url":"<step5端点>","api_key":"<KEY>", "model":"step5", "default":false},
}
ACTIVE_MODEL = env.get("ACTIVE_MODEL","hy3")   # 或前端实时切换
  • 对比用法：同一只股票分别用 hy3 / step5 生成短评，并列对比，验证哪个更贴合你的口味。
  • 回退机制：某模型超时/限流，自动降级到另一模型并提示。
  • ⚠️ 需你确认 step5 的接入方式（API 端点 / 密钥 / 是否同平台）。
